# Project operations viewer

A standalone read-only dashboard. Open the complete share link to view the encrypted data snapshot.

The page has no sign-in service, analytics, remote scripts, or data API. Its data is decrypted locally using the key in the URL fragment; the key is not stored in this repository. No plaintext project data or administrative functions are included.

The displayed data is a published snapshot, not a live connection to a reporting system. See `THIRD_PARTY_NOTICES.txt` for bundled dependency licenses.
